# Akshaya Janakiraman: portfolio

Personal portfolio site: projects, experience, skills and CV.

**Live site:** https://akshayaj0286-svg.github.io/Portfolio/

Built with plain HTML and CSS, with no build step, and hosted free on GitHub Pages.

## Files

- `index.html`: the whole site
- `assets/Akshaya-Janakiraman-CV.pdf`: CV download
- `assets/reporting-pipeline-preview.png`: project screenshot

## Updating

- **CV:** replace `assets/Akshaya-Janakiraman-CV.pdf` with a new file of the same name.
- **Departures board:** each `<tr class="row-link">` in `index.html` is one row. `data-target` is the section it jumps to.
- **New project:** copy an `<article class="project">` block and edit the text.
